# Проект "Интернет-магазин Skystore"

## Описание
Проект "Интернет-магазин Skystore" - это небольшое приложение для различных товаров.

## Установка

1. Клонируйте репозиторий
git clone https://github.com/ksen6423/HW22Django
2. Установите зависимости
pip install -r requirements.txt
 
## Использование

1. Откройте главную страницу приложения
2. Используйте контакты для обратной связи
3. Добавлены модель Product и Category
